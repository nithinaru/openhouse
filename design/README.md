# openhouse — design explorations

All screens were designed in Paper (file: **Openhouse — Mobile UI**, https://app.paper.design/file/01M7GCDC71CE495KQMWDX0BYAD) and exported at 2x (780×1688). Each folder is one direction; each has its own README with mood, palette, type and screen notes.

| Folder | Direction | Status |
| --- | --- | --- |
| `a-darkroom/` | Photoreal dollhouse, darkroom palette, editorial serif | exploration |
| `b-archival/` | Archival documentary: 16mm, grease pencil, catalog cards | exploration |
| `c-pixel-painting/` | Painterly pixel mosaic with LED dot mask | exploration |
| `d-dogpatch-pixel-blueprint/` | Dogpatch HQ venue in pixel + blueprint, orbit home | exploration (blueprint dropped) |
| `f-interior-only/` | Interior-only reconstructions in A + C styles | exploration |
| `rebrand/` | Full rebrand: sky, chrome wordmark, sticker cutouts | **current** |

## Product constraints that shaped later directions

- **Interior only.** We will not have exterior captures, so the venue is shown as a floating cluster of reconstructed rooms (Matterport-style dollhouse), never a facade.
- **Partial coverage is a feature.** Captured rooms render; uncaptured rooms are ghosted with an "add yours" prompt. Same for the 360° view inside a room.
- **People as cutouts.** In the rebrand, each contributor is a cardboard standee placed where they stood; tapping one shows the night from their photos.

## Caveats

- Imagery is AI-generated placeholder art, not real captures. Dogpatch HQ is a plausible stand-in, not the actual building.
- People in the rebrand are fictional.
