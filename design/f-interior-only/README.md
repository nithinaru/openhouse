# F — Interior only (A + C)

Response to the constraint that we only capture interiors.

- Home = a floating cluster of reconstructed rooms. Captured rooms render; edges dissolve where no photos exist; uncaptured rooms are wireframe ghosts tagged "0 frames · add +".
- "Rooms remembered" coverage bar (3 / 14).
- Inside = turn in place. A 360° dial shows facing direction and captured arc ("280° seen"); the uncaptured side fades to dither with "add a photo from here".
