# B — Archival documentary

Mood: an editor's film vault. Each event becomes a short documentary of the night.

- Palette: `#0B0A08` acetate black · `#ECE4D2` print stock · `#BFA678` manila · `#7D766A` faded emulsion · `#C2321D` grease-pencil red
- Type: Instrument Serif (title cards), Courier Prime (typewritten captions, subtitles), IBM Plex Mono (burned-in timecode), Helvetica Neue Condensed (slate labels)

Screens
1. `b1-archive-cover` — catalog card for the venue with an ON FILE stamp
2. `b2-reels-through-time` — each event is a 16mm strip; selected frame circled in grease pencil
3. `b3-inside-annotated` — room annotated like a contact sheet, manila slip on the active memory
4. `b4-the-night-recap-film` — recap film: chapter card, subtitle, five-chapter reel, credits
